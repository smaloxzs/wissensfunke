# Wissensfunke

Jeden Tag eine kurze Lektion Allgemeinwissen, mit Quiz und Wiederholung. Gedacht als Alternative zum endlosen Scrollen.

**Zur App:** https://smaloxzs.github.io/wissensfunke/

## Was drin ist
- 60 Lektionen in 20 Themenwelten, von Geschichte und Weltraum über Politik, Mathe und Sprache bis zu Mythen, Sport, Essen und Film
- Lektion des Tages, Zufallslektion und Blitzquiz
- Quiz mit fünf Fragetypen: Multiple Choice, Richtig/Falsch, Lückentext, Reihenfolge, Zuordnen
- Wiederholung nach dem Prinzip der verteilten Wiederholung (Spaced Repetition)
- Serie, XP, Level und Tagesziel
- Läuft im Browser, auch offline, und lässt sich in Chrome als App installieren

Der Fortschritt wird nur im eigenen Browser gespeichert. Über „Sicherung kopieren“ im Profil lässt er sich auf ein anderes Gerät übertragen.

## Technik
Reines HTML, CSS und JavaScript ohne Build-Schritt. Die Lerninhalte liegen in `content/c1.js` bis `content/c6.js`.
